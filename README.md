# 海康监控 IP 对调（临时 IP 中转）

把杂乱的监控 IP 理顺：源 IP 改到目标 IP。若目标已被占用，经你指定的**临时 IP**中转完成对调，并同步更新录像机数字通道。

风格与姊妹项目一致：纯 Python 标准库 + tkinter，ISAPI Digest/Basic，不用 Cookie / SessionTag / 官方 SDK。

---

## 为什么要临时 IP

不能把 `192.168.22.100` 直接改成已被占用的 `192.168.22.166`（冲突）。正确顺序：

1. 三重校验临时 IP 空闲（ICMP ping / HTTP deviceInfo / 跨录像机通道）
2. 占用方 `166` → 临时 IP，立刻改其录像机通道
3. 源 `100` → `166`，立刻改其录像机通道
4. 占用方 临时 IP → `100`，立刻改其录像机通道（完成对调）

目标空闲时跳过占用方步骤，只做源改址 + 通道更新。

---

## 源码运行

需要本机 Python 3.10+（仅标准库）。

```text
双击「打开IP对调.bat」
```

或：

```bash
python swap_gui.py
```

1. 填 **源 IP / 目标 IP / 临时 IP**
2. 填录像机默认账号密码、摄像头账号密码（改 IP 必填）
3. 录像机列表默认 `23.251`～`254`，可按行覆盖账号
4. 先勾 **只演练**，点「检查计划」看步骤
5. 确认后再取消勾选，点「开始对调」

---

## 注意

- 每改完一台摄像头 IP，立刻 **就地改** 对应录像机通道里的 IP（不删通道、不改 D 号）
- 固件若拒绝就地改 IP，会直接报错停止，不会删加通道
- 失败会停在当前步并写明已完成步数，便于手工收尾
- 临时 IP 只要 ping / HTTP / 录像机通道任一命中，一律中止并要求换地址
